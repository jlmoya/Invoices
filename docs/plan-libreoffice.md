# Plan de adaptación a LibreOffice

Diseño: [diseno-libreoffice.md](diseno-libreoffice.md).

1. Mover el conjunto original a `access/` conservando sus bytes y preparar las carpetas equivalentes de `libreoffice/`.
2. Adaptar las guías 1–5 y sus planes: configuración, tipos, importación con Calc, normalización y SQL Firebird, formularios y reporte.
3. Adaptar las guías 6–8, evaluación y referencias: estructuras, diseño de objetos, clases Basic, persistencia SDBC y contrato de polimorfismo.
4. Implementar los catorce módulos Basic equivalentes; mantener la plantilla con tres ejercicios y la solución solo en el kit del instructor.
5. Crear índice común, instrucciones de kits, ilustración de Base y reglas de codificación por curso.
6. Verificar paridad, bytes del original, enlaces, sintaxis y comportamiento con LibreOffice instalado; corregir inconsistencias entre código y guías.
7. Guardar evidencia de verificación, revisar cambios, commit y push a origin según el encargo.

El trabajo de guías y código se distribuye por carpetas; la integración, revisión y publicación quedan en la sesión principal.
