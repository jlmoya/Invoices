## Guion

- Relaciona `Type` con `struct` y una tabla con una colección persistente de registros.
- Para el crecimiento logarítmico, adivina un número de 1 a 1 000 con preguntas de mayor o menor: bastan diez. Distingue esa búsqueda binaria de la implementación real de los índices Firebird.
- Enseña que la cuadrícula de diseño no expresa toda la integridad del esquema: `UNIQUE`, `CHECK` y valores predeterminados quedan documentados en SQL y son aplicados por el motor.
- Subraya la identidad: los CSV tienen IDs explícitos que sostienen referencias futuras. No omitirlos ni regenerarlos al importar. Después se reinicia la identidad; no se exige una secuencia sin huecos.
- El esquema manual de la guía es el trabajo del alumno. El constructor del kit es una ayuda para recuperación del instructor, no una solución que los estudiantes ejecuten antes de diseñar.

## Preguntas para la discusión

| Pregunta | Respuesta esperada |
| --- | --- |
| ¿Por qué no usar Double para precio? | Es aproximado; DECIMAL almacena decimales exactos y Currency los representa en Basic |
| ¿Dos decimales en pantalla garantizan exactitud? | No: el formato no cambia el tipo de almacenamiento |
| ¿Por qué teléfono y documento fiscal son texto? | No se calculan; tienen símbolos y ceros iniciales |
| ¿Qué pasa si indexo todo? | Aumentan espacio y trabajo en cada modificación |
| ¿La clave sustituta sustituye UNIQUE sobre el código? | No: identifica la fila, pero el código de negocio también debe ser único |

## Errores frecuentes

| Síntoma | Causa | Solución |
| --- | --- | --- |
| No se pudieron anexar todas las filas | Quedaron pruebas o se importó dos veces | Verificar conteos y IDs; no aceptar omitir errores y continuar con carga parcial |
| Fecha aparece como número o texto | Calc interpretó mal el CSV | Reabrir con Fecha AMD en esa columna, comprobar antes de copiar |
| Precio se multiplicó o quedó texto | Idioma decimal incorrecto en importación | Inglés EE. UU. y punto decimal en la vista previa |
| Faltan ceros del documento fiscal | Calc lo convirtió a número | Reabrir CSV con columna Texto; formatear después no recupera los ceros |
| Acentos extraños | Se eligió otra codificación | UTF-8 en Importar texto |
| Se creó otra tabla o una nueva clave | Se eligió Definición y datos | Anexar datos a tabla existente; comprobar destino y asignación de columnas |
| No existe tabla/columna en SQL | Se omitieron comillas o cambió la capitalización | Usar `"tblClientes"` y los campos exactos del esquema |
| Alta automática choca con un ID | Contador no avanzó con IDs explícitos | Firebird 3: RESTART WITH máximo; versiones posteriores: próximo valor |
| Selector no muestra una rutina con parámetros | El selector busca procedimientos invocables sin argumentos | Ejecutar wrapper o crear un Sub auxiliar sin parámetros |

## Solución de la tarea 2

Un diseño válido tiene nueve campos. Ejecuta la sentencia en Herramientas → SQL y justifica cada restricción:

```sql
CREATE TABLE "tblProveedores" (
    "IdProveedor" INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    "DocumentoFiscal" VARCHAR(20) NOT NULL UNIQUE,
    "RazonSocial" VARCHAR(100) NOT NULL,
    "Contacto" VARCHAR(100),
    "Telefono" VARCHAR(20),
    "Correo" VARCHAR(100) CHECK ("Correo" IS NULL OR "Correo" LIKE '%@%.%'),
    "DiasCredito" INTEGER DEFAULT 0 NOT NULL CHECK ("DiasCredito" BETWEEN 0 AND 120),
    "Activo" BOOLEAN DEFAULT TRUE NOT NULL,
    "FechaAlta" DATE DEFAULT CURRENT_DATE
);
```

El ID da identidad estable; documento es texto único; nombres tienen un límite razonado; teléfono no se calcula; correo es nullable con filtro elemental; crédito admite enteros de 0 a 120; activo es un indicador; fecha usa un valor de calendario. Se acepta otro diseño si sus decisiones están justificadas.

Buscando el último código, pasos esperados: lineal 1 000, 10 000, 100 000; binaria aproximadamente 10, 14, 17. La lineal se multiplica por diez; la binaria añade unos tres o cuatro pasos. Evalúa las comparaciones antes que tiempos, que dependen del equipo.

Cada índice ocupa espacio y exige mantenimiento al insertar o cambiar. No todos los campos se buscan ni un índice siempre mejora una consulta.

## Respuestas de la autoevaluación

1. Texto: puede empezar con cero y no participa en cuentas.
2. DECIMAL y Currency conservan cuatro decimales; Double representa aproximaciones binarias.
3. Natural: `Codigo` o `DocumentoFiscal`. Sustituta: `IdProducto` o `IdCliente`.
4. 21 pasos: duplicar n añade aproximadamente uno.
